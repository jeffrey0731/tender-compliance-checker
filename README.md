一个适配 Claude Code / Codex / WorkBuddy 等 Agent 环境的招标文件合规审查技能，基于结构化切片架构，对招标/采购文件进行多维度合规性审查，输出精确定位的风险报告。

> 当前版本 **v1.1.0**（2026-08-26 核验）。完整变更见 `SKILL.md` 顶部 `change_log`。

## 核心特性

- **切片驱动审查**：不将长文本全量灌入 LLM，先对招标文件做结构化语义切片，再按维度定向检索
- **35 维度 · 六层架构**：A 共享层 / B 招标投标法专属层 / C 政府采购法专属层 / D 非招标方式专属层 / E 内控制度层 / F 特殊采购主体层，覆盖资质门槛、评分办法、时间节点、废标条款、合同一致性、法规引用、串通投标、排斥潜在投标人、**公平竞争审查(A13)**、**履约验收(A14)**、EPC、框架协议采购、军队/央企采购等
- **双法体系适配**：自动判定适用招标投标法体系或政府采购法体系，引用对应法规
- **精确溯源定位**：每条风险发现绑定章节、条款号和页码，原文摘录与原件完全一致
- **交叉校验**：跨维度矛盾检测（共 17 项），识别"量身定做"、程序违规、补遗/澄清冲突等深层风险
- **五级风险 + 证据强度**：高风险 / 中风险 / 低风险 / 争议项 / 待确认，分级处置；每条风险标注证据强度（强/中/弱），弱证据仅作"疑似/建议核实"提示，不直接定性违规
- **确定性工具资产**：内置法定时限速查表、红旗关键词正则库、Python 切片参考脚本、PDF/DOCX 提取指引，减少 LLM 现编
- **少样本自检**：附高质量风险范例与输出前自检清单，保证输出一致、不漏步骤

## 适用场景

- 招标代理机构内部审核招标文件发布前的合规性
- 投标人自行检查招标文件中的排斥性条款
- 法务部门对采购文件的合规性把关
- 评标前的文件规范性预审

## 审查维度（六层架构）

| 层级 | 覆盖范围 | 代表维度 |
|------|---------|---------|
| A 共享层 | 所有采购通用 | 资质门槛、评审办法、时间节点、废标/否决、合同一致性、法规引用、排斥潜在投标人、串通投标、**公平竞争审查(A13)**、**履约验收(A14)** |
| B 招标投标法层 | 工程/货物/服务招标 | 招标条件、投标人资格、评标委员会、中标、投诉、**EPC 工程总承包(B4)** |
| C 政府采购法层 | 政府采购 | 采购方式、评审办法、政策功能（中小企业/节能/绿色）、合同、**框架协议采购(C7)** |
| D 非招标方式层 | 谈判/磋商/询价/单一来源 | 适用范围、程序合规、成交标准 |
| E 内控制度层 | 单位内控 | 决策审批、岗位分离、档案管理、验收与付款分离 |
| F 特殊主体层 | 军队/央企采购 | 军队采购(F1)、中央企业采购(F2) |

> 维度按「项目画像 + 法律体系判定」动态激活，并非每次全量审查。

## 风险等级与证据强度

| 等级 | 判定标准 | 处置建议 |
|------|---------|---------|
| 🔴 高风险 | 违反法律/行政法规强制性规定 | 必须整改 |
| 🟡 中风险 | 违反部门规章程序性规定或存在歧义 | 建议整改 |
| 🟢 低风险 | 不违反强制性规定但与惯例有偏差 | 可选改进 |
| ⚪ 争议项 | 法规未明确规定或实践中有不同理解 | 列明观点 |
| 🔵 待确认 | 信息不足或置信度低于70% | 提示人工核实 |

每条风险另标注 **证据强度**（强 / 中 / 弱）：

- **强**：有明确法条 + 原文摘录，可直接定性
- **中**：有依据但需结合上下文判断
- **弱**：仅疑似或信息不足，措辞限用「疑似 / 可能 / 建议核实」，不直接定性违规

## 适用法规体系（部分）

- 《中华人民共和国招标投标法》及实施条例
- 《中华人民共和国政府采购法》及实施条例
- 《政府采购货物和服务招标投标管理办法》（财政部令第87号）
- 《评标委员会和评标方法暂行规定》
- 《工程建设项目施工招标投标办法》
- 《电子招标投标办法》（发改委令第20号）
- 《公平竞争审查条例》（国务院令第783号）及招标投标领域公平竞争审查规则（2024）
- 《政府采购框架协议采购方式管理暂行办法》（财库〔2022〕110号）
- 《财政部关于进一步加大政府采购支持中小企业力度的通知》（财库〔2022〕19号）
- 《财政部关于进一步加强政府采购项目和履约验收管理的指导意见》（财库〔2016〕205号）
- 《房屋建筑和市政基础设施项目工程总承包管理办法》（建市规〔2019〕12号）
- 军队物资采购管理规定、中央企业采购管理相关规定（2024）

> 法规清单与生效时点见 `SKILL.md` 附录四「法规时效性台账」，建议每 6–12 个月复核一次。

## 工作流程

```
材料接收(含补遗/澄清) → 文件解析与切片 → 项目画像生成 → 法律体系判断
    → 分层维度定向审查 → 交叉校验(17项) → 风险评级(含证据强度) → 输出报告(少样本) → 输出前自检
```
