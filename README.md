一个适配 Claude Code / Codex 等 Agent 环境的招标文件合规审查技能，基于结构化切片架构，对招标/采购文件进行多维度合规性审查，输出精确定位的风险报告。

## 核心特性

- **切片驱动审查**：不将长文本全量灌入 LLM，先对招标文件做结构化语义切片，再按维度定向检索
- **15 维度全覆盖**：资质门槛、评分办法、时间节点、废标条款、合同一致性、法规引用、串通投标风险等
- **双法体系适配**：自动判定适用招标投标法体系或政府采购法体系，引用对应法规
- **精确溯源定位**：每条风险发现绑定章节、条款号和页码，原文摘录与原件完全一致
- **交叉校验**：跨维度矛盾检测，识别"量身定做"、程序违规等深层风险
- **五级风险评定**：高风险 / 中风险 / 低风险 / 争议项 / 待确认，分级处置

## 适用场景

- 招标代理机构内部审核招标文件发布前的合规性
- 投标人自行检查招标文件中的排斥性条款
- 法务部门对采购文件的合规性把关
- 评标前的文件规范性预审

## 审查维度

| 序号 | 维度 | 重点检查内容 |
|------|------|-------------|
| 1 | 资质门槛合规性 | 注册资本歧视、地域限制、指定品牌、冗余资质 |
| 2 | 评分办法合理性 | 价格分权重、主观分比例、量身定做嫌疑 |
| 3 | 时间节点合规性 | 发售期、澄清期、质疑期、公示期法定时限 |
| 4 | 废标/否决投标条款 | 条款清晰性、法定否决情形完整性 |
| 5 | 合同条款一致性 | 价格、工期、质量、付款与招标承诺一致性 |
| 6 | 法规引用准确性 | 条款号准确性、是否过期废止 |
| 7 | 保密要求合规性 | 公告发布、投标人信息保护 |
| 8 | 进口产品审批 | 审批手续完整性 |
| 9 | 串通投标风险识别 | 量身定做、评分指向性、信息不对称 |
| 10 | 排斥潜在投标人 | 区域限制、行业经验限制 |
| 11 | 采购方式合规性 | 是否达到公开招标标准 |
| 12 | 公告发布合规性 | 媒介、内容、期限 |
| 13 | 投标有效期合规性 | 期限合理性 |
| 14 | 履约保证金合规性 | 比例上限、退还条件 |
| 15 | 评标委员会组建 | 专家人数、占比、回避要求 |

## 风险等级

| 等级 | 判定标准 | 处置建议 |
|------|---------|---------|
| 🔴 高风险 | 违反法律/行政法规强制性规定 | 必须整改 |
| 🟡 中风险 | 违反部门规章程序性规定或存在歧义 | 建议整改 |
| 🟢 低风险 | 不违反强制性规定但与惯例有偏差 | 可选改进 |
| ⚪ 争议项 | 法规未明确规定或实践中有不同理解 | 列明观点 |
| 🔵 待确认 | 信息不足或置信度低于70% | 提示人工核实 |

## 适用法规体系

- 《中华人民共和国招标投标法》及实施条例
- 《中华人民共和国政府采购法》及实施条例
- 《政府采购货物和服务招标投标管理办法》（财政部令第87号）
- 《评标委员会和评标方法暂行规定》
- 《工程建设项目施工招标投标办法》等

## 工作流程

```
材料接收 → 文件解析与切片 → 项目画像生成 → 法律体系判断
    → 15维度定向审查 → 交叉校验 → 风险评定 → 输出报告
```
